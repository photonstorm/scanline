CAUSE: The page enables the scissor test (gl.enable(SCISSOR_TEST)) and sets gl.scissor(12, 336, 150, 12) at the end of each frame, for the health bar, and never disables it. The next frame starts with the scissor still on, so every clear and draw is clipped to that 150x12 box and the rest of the canvas stays black.

EVIDENCE: cap_3 (frame 105) reports "21 draws changed no pixels", and that "Events 0, 4 clear with the scissor test on (box 12,336,150,12) ... frame began with scissor test already on: an earlier frame left it on". draw 1 shows "scissor test ON, box 12, 336, 150, 12" with its uniforms (rect, resolution, tint) set correctly, so the geometry was fine. The scissor box is in GL coordinates (bottom-left origin), which puts it at the top-left of the canvas. The commands table shows command 138 gl.enable [3089] and command 139 gl.scissor [12,336,150,12], both late in the frame, after the last draw.

FIX: Call gl.disable(gl.SCISSOR_TEST) after the health-bar draw. Alternatively, enable and set the scissor only around that draw and disable it afterwards. Calling gl.disable(gl.SCISSOR_TEST) at the start of each frame also works.
