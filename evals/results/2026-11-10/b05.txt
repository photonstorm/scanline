CAUSE: The main pass clears the canvas depth buffer to 0 (clearDepth(0)) while using depth test LESS. No scene fragment (depth 0.5 or 0.9) is less than 0, so every depth-tested draw is rejected.

EVIDENCE: In cap_7, event 4 (the clear to canvas) reads "clears to colour 0.35, 0.6, 0.9, 1, depth 0, stencil 0". Events 5-21 (ground, crates, glass, sparks) all run with depth test LESS. Draw 5 (ground, depth = 0.9) and draw 6 (crate, depth = 0.5) both report "changed no pixels of its target ... every fragment was rejected". Sparks and glass use depth LESS with no write, so they fail the same test. Events 22-24 (HUD, minimap) have depth test disabled (draw_diff 6 vs 22 shows DEPTH_TEST absent), so they draw. The sky is just the colour clear.

FIX: Clear depth to 1.0: gl.clearDepth(1.0), or remove the clearDepth(0) call. Alternatively use depthFunc GREATER, but then the depth uniforms would need rethinking.
